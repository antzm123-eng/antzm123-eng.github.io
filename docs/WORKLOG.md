## 2026-09-01 — 호스팅을 Netlify → GitHub Pages 로 이전

**배경** 사이트는 이미 `gloudy.netlify.app` 으로 공개 서비스 중이었다.
(CLAUDE.md 에는 "미공개"로 잘못 적혀 있었음 — 실제와 문서가 어긋나 있었다.)
Netlify 무료 플랜이 크레딧을 소모하는 것을 사용자가 발견해 검토했다.

**조사 결과**

| 항목 | 수치 |
|---|---|
| Netlify 무료 | 300크레딧/월, **하드캡**(소진 시 사이트 정지) |
| 배포 1회 | 15크레딧 = 월 한도의 **5%** |
| 대역폭 | 20크레딧/GB → 월 15GB |
| GitHub Pages | 무료 · 100GB/월 · 사이트 1GB 한도 |
| 이 사이트 크기 | 93MB (1GB 한도의 9%) |
| Netlify 전용 기능 사용 | **0개** (폼·함수·리다이렉트·netlify.toml 전부 없음) |

8월 커밋 19개. 푸시마다 배포됐다면 285크레딧(월 한도의 95%)이
**방문자 없이 개발만으로** 소모된다. 결정적으로 이 사이트는 Netlify 고유 기능을
하나도 쓰지 않는다.

**추가 발견** `canonical` / `og:url` / `og:image` 가 전부
`antzm123-eng.github.io/gloudy/` 를 가리키는데 그 주소는 404였다.
즉 Netlify 로 서비스하는 동안 **링크 공유 미리보기가 깨져 있었다.**
GitHub Pages 로 옮기면 태그를 손대지 않아도 저절로 맞아떨어진다.

**조치**
- `.nojekyll` 추가 — GitHub Pages 의 Jekyll 처리를 끔 (정적 파일 그대로 서빙)
- 사용자가 아직 아무에게도 주소를 알리지 않은 상태여서 주소 변경 부담 없음
- Netlify 프로젝트는 GitHub Pages 동작 확인 후 **삭제**하기로 함
  (무료 플랜에는 '비공개' 기능이 없어 삭제가 유일한 완전 중단 방법)
- (같은 날 완료) GitHub Pages 켜짐 확인. 이미지 252개 전수 200 응답, 콘솔 오류 0,
  `canonical`/`og` 태그가 실제 주소와 일치 → Netlify 시절 깨져 있던 링크 미리보기 정상화
- Netlify 프로젝트 삭제 완료 (`gloudy.netlify.app` → 404 확인)

### 같은 날 — 경력 역할 비중 정정

사용자가 실제 업무 비중을 설명해 사실관계를 바로잡았다. **회사는 교육과 공간기획·조성
두 축인데, 사용자의 주력은 공간기획·조성이고 교육은 보조**였다. 기존 문서는 교육을
주력처럼 보이게 배치돼 있었다.

| 항목 | 전 | 후 |
|---|---|---|
| 직무 큰 줄 | 브랜드 마케팅 · 비주얼 디자인 | **공간 기획·조성 · 브랜드 마케팅 · 운영** |
| 직무 작은 줄 | 로컬 콘텐츠 기획 · 공간 기획 · PM | 비주얼 디자인 · 로컬 콘텐츠 기획 · **교육 프로그램 보조** |
| 담당 업무 순서 | 마케팅 → 공간 → 교육 | **공간 → 마케팅 → 교육(보조)** |
| 교육 표현 | "기획·진행", "운영해" (주도로 읽힘) | **"운영을 보조했고"** + 문서·통계는 본인 주도로 구분 |
| 성과 순서 | 시각물 → 행사 → 교육 → 공간 | **공간 → 행사 → 시각물 → 교육** |
| 조직 규모 | 없음 | 기간 칸에 **"대표 포함 2인 조직"** 추가 |

`비주얼 디자인`을 작은 줄로 내린 것은 손해가 아니다. 바로 위 Work 섹션의 작업 24개가
디자인 역량을 이미 증명하므로, 경력란은 **Work 가 보여주지 못하는 것**을 맡는 게 낫다.

"대표 포함 2인 조직"은 같은 성과의 **밀도**를 바꾼다. 큰 조직의 한 명이 아니라
둘이서 전부 감당했다는 뜻이 되기 때문이다.

**검증** 콘솔 오류 0 · 1280px/375px 가로 넘침 0 · 담당업무 3줄 · 성과 4줄

강제 푸시의 위험이 이득보다 크고, GitHub 서버에는 어차피 흔적이 남는다.

- 워터마크 임시 파일 확장자를 `.wm` 으로 써서 **PNG 파일에 JPEG 데이터가 들어감**
  (design 폴더가 12MB→4MB 로 줄어든 것이 단서) → 백업 복원 후 원본 확장자 유지하도록 수정
- 푸터가 원래 있었는데 새로 하나 더 만들어 중복 → 하나로 통합
